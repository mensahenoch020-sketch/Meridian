# Meridian interface

Meridian uses a traditional retail banking layout with its own identity: burgundy navigation, a warm gold accent, serif greetings, clear account cards, and understated SVG icons.

The overview shows the actual USD and BTC balances returned by the API, recent ledger activity, and actions connected to the existing transfer, wallet, settings, and profile screens. It does not add unsupported deposit, credit card, or external payment functions.

Navigation moves to the bottom of the screen on phones. Forms, account settings, receipts, and the admin console share the same design system. Existing account data and API behavior remain unchanged.

This design is an independent Meridian interface, not a reproduction of another bank's current screens or branding. Browser checks exercise the banking flows and capture the interface at 390, 768, and 1440 pixel widths.
